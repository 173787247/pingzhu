# v0.10.1 — 空白改为「先开候选单、再接受」

## 一句话

打完字按空白，**现在会先列出候选**；再按一次空白才送出。想选第二个的人这就能选到了。

## 为什么改

`5j4u4`（ㄓㄨˋ-ㄧˋ）有两种正确的读法：

```
ㄓㄨˋ-ㄧˋ  → 注意   ← 原本按空白直接送出的
ㄓㄨ-ㄧˋ    → 助益   ← 在同一张候选单上排第 2
```

两个都对，只是切分不同。**但原本按空白只会得到「注意」** —— 想选「助益」的人
必须**事先知道**要按 `↓` 才看得到那张单子。而这正是空白要解决的问题：它是大家
拿来「接受」的键，所以它必须能以接受收尾。

翻页因此移到 `↓`（它本来就是「开单／翻页」一键）。原本「开着就翻页」的规则有
两个毛病：第二个候选到不了，以及**最常按的键去卷一张没人要求卷的清单**。

## 空白的三态

| 状态 | 按空白 |
|---|---|
| 组字中、没有候选 | 送出（打了一半，没有东西可挑） |
| 组字中、有候选、候单未开 | **开单，不送出** |
| 候单开着 | 送出目前那一个 |
| 没在组字 | 一般空白 |

## 操作对照

```
5j4u4        只打字            首选 注意
5j4u4 ␣      开单              注意 助益 註譯 …
5j4u4 ␣ 2    选第 2 个          助益
5j4u4 ␣ 1    选第 1 个          注意
5j4u4 ␣ ␣    送出首选           注意
5j4u4 ␣ ↓ …  翻页（↓ 可重复按）
su3cl3 ␣ ␣   你好
2l3 ␣ ␣      導
```

## ★ 升级后你会立刻感觉到的一件事

**最高频的动作——打完就送出——从一次空白变成两次。**

这是刻意的取舍，不是疏漏：要让「第二个候选到得了」与「空白以接受收尾」同时
成立，第一次按下就不能送出。如果你更想要「一次空白直接送出」，那第二个候选
就必须继续靠 `↓`，也就是回到 v0.10.0 的行为。

## 另外修掉一个既有缺陷

**Windows 的 `↓` 从不翻页** —— 候选单开着时它仍回传「开单」，而 macOS、Android
与文件都写着「`↓` 一键开单与翻页」。现在四个外壳一致。
