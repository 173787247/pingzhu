## 1. 公司與產品線

## 4. 功能清單（V13 專業版）

官方標示 ⭐ 者為「經過使用者調查，用戶離不開自然輸入法」的功能。

**智慧核心**

- ⭐ 人工智慧聰明選字（語意處理，號稱降低選字率）
- ⭐ 聰明自動學習：打過 1 次即記憶，打過 3 次即永久記憶
- ⭐ 智慧中英切換（V13 獨佔，僅支援標準注音）：輸入空白、符號或倒退鍵自動回中文模式
- ⭐ 空白鍵三種模式：輸入空白／快速切換常用字（前五字）／開啟候選列表
- 手動強制斷詞：以 `Tab` 在游標處斷詞
- 近音表選字：按 `↑` 顯示同音字（針對 ㄗㄓ、ㄣㄥ 不分）
- 部首筆畫表：`Ctrl`+`↑` 切換

**輸入法支援**

- 注音：標準鍵盤、許氏鍵盤、倚天鍵盤、倚天 26 鍵
- 漢語拼音、通用拼音（可輸出護照拼音）
- 倉頡（三代、五代）、簡易（速成）
- 可自行新增慣用輸入法

**效率功能**

- ⭐ 數字快打：中文數字、千分位、計算機、日期、時間格式
- ⭐ 英文聯想：例如輸入 `vby` 帶出 vocabulary
- 成語快打：`【,】+【,】` 後輸入任兩字首音
- 記憶首碼快打：輸入前三碼注音首音，帶出曾輸入的長句
- ⭐ 個人詞庫、⭐ 文字範本、⭐ 長句聯想、⭐ 符號表（內建 48 組、可自訂至 500 組）
- 詞語隨身包（匯出／匯入）、CSV 匯出匯入、⭐ 雲端同步詞庫共享
- 暫存詞批次匯入個人詞庫
- ⭐ 輕鬆打出簡體字（繁簡一鍵切換）

**其他**

- 顯示對應碼（同步顯示注音／拼音／倉頡碼）
- ⭐ 打字同步發音（校稿、教學）
- 暗黑模式、字體縮放、工具列大小調整（僅 Windows）、隱藏工具列
- 中英切換鍵可選 CapsLock 或 Shift（Mac 也能用 Shift）

## 5. 使用者痛點：客服中心本身就是證據

把 201 篇客服條目按主題分類：

| 主題 | 篇數 | 佔比 |
|---|---|---|
| **授權／訂閱／付款** | **51** | **25%** |
| 功能操作 | 33 | 16% |
| 安裝／移除／更新 | 32 | 16% |
| Mac 專屬 | 20 | 10% |
| Windows 專屬 | 19 | 9% |
| 其他產品線（文字MP3／VoAI／快合規…） | 13 | 6% |
| 其他 | 33 | 16% |

**四篇官方文件裡就有一篇在處理授權、訂閱或付款問題**，而不是在教使用者打字。
實際條目標題（節錄）：

- 【授權問題】授權狀態尚未更新，請重新登入／註冊以便立即更新
- 【訂閱版】授權已滿，如何移除授權？
- 【授權移轉】換電腦或電腦壞了的時候，如何將自然輸入法從舊電腦移到新電腦？
- 【授權移轉】換電腦要如何操作
- 【Windows】註冊後又出現授權到期
- 【訂閱版】訂閱服務扣款失敗該怎麼處理
- 【訂閱版】登入失敗、帳號無法登入
- 【取消訂閱】自然輸入法訂閱版
- 【Windows】換電腦如何登出
- 【免費版】Mac 有免費版嗎？
- 【訂閱版】訂閱制如何更換方案（且官方說明：剩餘到期日大於 60 天就不能換方案）

這些不是「功能不好用」，而是**授權機制本身在使用者與客服之間製造工作量**。
對一個平替專案來說，最直接的差異化不是做得更聰明，而是**不要有這些問題**。

媒體面也有訊號：2026-06 中時新聞網〈「這兩詞」每次都要重選 網怒微軟注音是史上最爛
大推這2種輸入法〉——使用者對現有選字品質的不滿是持續存在的輿論主題。

## 6. 平替的切入點

| 缺口 | 平注的對策 |
|---|---|
| 沒有 Android／iOS | Android 外殼列為 M6；行動端是最大的一片空白 |
| 沒有 HarmonyOS | 列入研究（見 [03](03-platform-matrix.md)），純鴻蒙生態目前無成熟注音輸入法 |
| 沒有 Linux | fcitx5 addon 為選配（成本低，生態現成） |
| 授權摩擦 | 核心寬鬆授權、離線可用、不強制帳號 |
| 訂閱制與台數限制 | 無台數概念，裝置數不受限 |
| 買斷限當年版 | 開源即無版本鎖 |
| 學習曲線／鍵盤 | 直接支援大千式、倚天式；許氏與倚天 26 需權威來源再補（見 [04](04-data-and-licensing.md)） |
| 資料鎖在雲端 | 詞庫為純文字 TSV，可自由匯出匯入 |

**不以「打倒自然輸入法」為目標**。它在 Windows 桌面上的成熟度（30 年打磨的選字、
注音/拼音/倉頡多模、數字快打、同步發音）短期內不可能全面追平。平注的目標是
**把「打注音」這件事在它不存在的平台上做到可用、可信、可長可久**。
