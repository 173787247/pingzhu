> 取证日期：2026-09-26 ｜ 资料来源：iqt.ai 官网、text.tw 产品站、support.iqt.ai 客服中心（Zendesk 公开 API，201 篇）、

## 1. 公司与产品线

网际智慧股份有限公司（IQ Technology Inc.），官网版权宣告为 **Copyright © 1995–2026**。

但**产品本身比公司更老**：自然输入法全名「自然智慧型中文输入系统」，1990 年由
**中央研究院资讯科学研究所许闻廉博士**发明，早期称为「**国音输入法**」，
技术主轴是 1993 年与陈克健共同发表的〈「自然」智慧型输入系统的语意分析─脉络会意法〉。
官方早期沿革页自述：以「全句语意分析」为原则、用样式比对建立字词的环境特征，
经**八百万字报纸语料**测试，平均正确率达 **95%**。

**这代表两件事**：

1. 这个产品线已经累积了 **35 年**的语意分析研究成果。任何平替专案在「选字聪明度」上
   短期内不可能追平——这是必须承认的前提。
2. 它的**技术路线是「脉络会意法」**（pattern matching + 上下文特征），
   而不是单纯的字频／词频统计。这解释了为什么它在上下文选字上长期领先。

### 在台湾输入法史上的地位

- **把「自动选字」变成商品**：在微软新注音成熟之前，就以脉络会意法提供可用的整句输入。
- **许氏键盘的发明地**：许氏键盘由许闻廉所创（25 键、声韵不分离），
  这也是为什么自然输入法对许氏键盘的支援是「原生」而非「相容」。
- **司法体系的实质标准**：司法院委托 IQT 将大易的「追音输入法」重写为
  「司法院智慧型输入法」，官方明言「每一套都包含了一套自然输入法软体在里面」。
  这是它进入公部门核心文书流程的直接证据。

### 现行产品线（iqt.ai 官网导览）

| 类别 | 产品 |
|---|---|
| 文字表达 | 自然输入法、追音输入法、台湾台语输入法（教育部专案）、EmojiBurger |
| 声音创作 | VoAI 绝好声创、AI NOWCAST、文字MP3 专业版、离线 TTS 引擎、TextMP3 |
| 广告合规 | XComply 快合规 |

**观察**：输入法本业已不是公司重心，重心明显转向 AI 语音与合规服务。
输入法产品线的更新因此变成「维护性更新为主」，并出现「三年一放生」的节奏
（V10 的 bug 不修就推 V11；V11 于 2022、V12 于 2025 停止维护）。

**注意**：IQT 在 iOS 上**有**产品——但那是教育部委托的「台湾台语输入法」
（台罗拼音，App Store v1.0.7，评分 4.62），**不是注音**。这反而更清楚说明
注音行动版是被策略性放弃的，而不是能力不足。

## 4. 功能清单（V13 专业版）

官方标示 ⭐ 者为「经过使用者调查，用户离不开自然输入法」的功能。

**智慧核心**

- ⭐ 人工智慧聪明选字（语意处理，号称降低选字率）
- ⭐ 聪明自动学习：打过 1 次即记忆，打过 3 次即永久记忆
- ⭐ 智慧中英切换（V13 独占，仅支援标准注音）：输入空白、符号或倒退键自动回中文模式
- ⭐ 空白键三种模式：输入空白／快速切换常用字（前五字）／开启候选列表
- 手动强制断词：以 `Tab` 在游标处断词
- 近音表选字：按 `↑` 显示同音字（针对 ㄗㄓ、ㄣㄥ 不分）
- 部首笔画表：`Ctrl`+`↑` 切换

**输入法支援**

- 注音：标准键盘、许氏键盘、倚天键盘、倚天 26 键
- 汉语拼音、通用拼音（可输出护照拼音）
- 仓颉（三代、五代）、简易（速成）
- 可自行新增惯用输入法

**效率功能**

- ⭐ 数字快打：中文数字、千分位、计算机、日期、时间格式
- ⭐ 英文联想：例如输入 `vby` 带出 vocabulary
- 成语快打：`【,】+【,】` 后输入任两字首音
- 记忆首码快打：输入前三码注音首音，带出曾输入的长句
- ⭐ 个人词库、⭐ 文字范本、⭐ 长句联想、⭐ 符号表（内建 48 组、可自订至 500 组）
- 词语随身包（汇出／汇入）、CSV 汇出汇入、⭐ 云端同步词库共享
- 暂存词批次汇入个人词库
- ⭐ 轻松打出简体字（繁简一键切换）

**其他**

- 显示对应码（同步显示注音／拼音／仓颉码）
- ⭐ 打字同步发音（校稿、教学）
- 暗黑模式、字体缩放、工具列大小调整（仅 Windows）、隐藏工具列
- 中英切换键可选 CapsLock 或 Shift（Mac 也能用 Shift）

## 5. 技术架构与隐私政策

### 5.1 引擎不是自研的（第三方揭露）

vChewing（小麦注音同作者的另一专案）的技术文件指出：**自然输入法 v10–v13 建构在
OpenVanilla 框架与「烟草注音引擎」（OVIMTobacco，姜天戬开发）之上**，
且**使用者词库是未加密的 SQLite 档（`profile.db`）**。

来源：[vchewing.github.io/manual/onboarding_goingime.html](https://vchewing.github.io/manual/onboarding_goingime.html)

这对平替专案的意义：

1. **它并非不可复制的黑盒子。** 一个 35 年的产品，其近代版本的引擎来自开源生态
   （OpenVanilla 为 MIT）。这说明「用开源零件组出商用注音输入法」是已被验证的路径。
2. **未加密的本地 SQLite 词库**是合理的设计（可携、可备份、可汇出），
   本专案采用纯文字 TSV 是同一哲学的更进一步。

### 5.2 隐私政策（2025-12-31 修订）

官方隐私权政策明示：云端备份资料加密上传后，**可去识别化为「综合性非个人资讯」**
（群体偏好、常用词），并**跨境传输（排除中国大陆）**、且**用于行销**。

来源：[iqt.ai/privacy](https://www.iqt.ai/privacy)

**本专案的对策很简单：不做云端同步、不做帐号系统。** 没有资料上传就没有这个议题，
也连带省下客服负担（见下一节）。词库的跨装置携带改用档案汇出汇入。

### 5.3 未发现资安事件或政府采购争议

本次调研**未找到**任何实际的资安事件报导或政府采购争议；政府共同供应契约仍在架上。
这点必须诚实记录——不应该用未经证实的「隐私疑虑」当作行销素材。

这些不是「功能不好用」，而是**授权机制本身在使用者与客服之间制造工作量**。
对一个平替专案来说，最直接的差异化不是做得更聪明，而是**不要有这些问题**。

媒体面也有讯号：2026-06 中时新闻网〈「这两词」每次都要重选 网怒微软注音是史上最烂
大推这2种输入法〉——使用者对现有选字品质的不满是持续存在的舆论主题。

## 7. 平替的切入点

### 市场结构：桌面付费商业注音只剩它一家

| 产品 | 平台 | 授权 | 状态 |
|---|---|---|---|
| 自然输入法 | Windows / macOS | 商业（买断／订阅） | 活跃，2026/09 安全性更新 |
| 新酷音 TSF | Windows | **GPL-3.0** | **极活跃，v26.1.1.0（2026/01/11）** |
| 小麦注音 McBopomofo | macOS | **MIT** | 活跃，3.1.1（2026/09/02） |
| RIME（小狼毫／鼠须管） | 多平台 | BSD-3（核心）／GPL-3（前端） | 活跃 |
| Yahoo!奇摩输入法 | Windows / macOS | 已开源（`yahoo/KeyKey`） | **2013/01/15 停止** |
| 微软注音 | Windows | 内建 | 使用者抱怨选字品质 |
| gcin / hime | Linux | — | gcin 仍维护；hime 2011 分岔 |
| Google 注音输入法／IQQI 智能输入法 | 行动 | — | **两者皆已从台湾 App Store 消失** |

两个关键事实：

1. **免费竞品的更新比付费产品更勤**（新酷音 TSF 2026/01 、小麦注音 2026/09），
   付费的正当性建立在「选字更聪明 ＋ 桌面整合 ＋ 客服」上。
2. **行动端曾经有产品（Google 注音、IQQI），现在都没有了。**
   这不是「没人做过所以不知道能不能做」，而是「做过、退了，现在是真空」。

### 对策

| 缺口 | 平注的对策 |
|---|---|
| 没有 Android／iOS | Android 外壳列为 M6；行动端是最大的一片空白 |
| 没有 HarmonyOS | 列入研究（见 [03](03-platform-matrix.md)），纯鸿蒙生态目前无成熟注音输入法 |
| 没有 Linux | fcitx5 addon 为选配（成本低，生态现成） |
| 授权摩擦 | 核心宽松授权、离线可用、不强制帐号 |
| 订阅制与台数限制 | 无台数概念，装置数不受限 |
| 买断限当年版 | 开源即无版本锁 |
| 「三年一放生」 | 开源＝停止维护时任何人都能接手 |
| 云端词库与去识别化利用 | 不做云端同步；词库为纯文字 TSV，可自由汇出汇入 |
| 键盘 | 直接支援大千式、倚天式；许氏与倚天 26 需权威来源再补（见 [04](04-data-and-licensing.md)） |

### 不应该假装做得到的事

**不以「打倒自然输入法」为目标。** 它在 Windows 桌面上的成熟度——
35 年的脉络会意法、注音／拼音／仓颉多模、数字快打、同步发音、司法院体系的实质标准地位——
短期内不可能全面追平。

平注的目标是**把「打注音」这件事在它不存在的平台上做到可用、可信、可长可久**，
并且在它做得到但让人付得痛苦的地方（授权、装置数、版本锁）提供一个没有摩擦的选择。
