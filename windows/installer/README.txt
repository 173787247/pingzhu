平注 PingZhu — Windows 注音输入法
==================================

版本：0.4.0
授权：MIT
网址：https://github.com/173787247/pingzhu


这是什么
--------

一个可以在 Windows 上打注音的输入法。托盘常驻，不需要安装驱动、不需要管理员权限、
不写入登录档的输入法设定。

它不是 TSF 文字服务，所以不会出现在语言列，也无法对「以系统管理员身分执行」的视窗
输入（那是 Windows 的 UIPI 限制）。记事本、浏览器、Office、多数应用程式都可以用。


安装
----

方法一（推荐）：双击 install.cmd

方法二：在 PowerShell 执行
    powershell -ExecutionPolicy Bypass -File install.ps1

安装位置：%LOCALAPPDATA%\Programs\PingZhu
会建立开始功能表捷径，并加入登入时自动启动（不想自动启动就加 -NoStartup）。

不想安装也可以用：直接双击 pingzhu-ime.exe，整个资料夹带著走。


操作
----

    Ctrl+Alt+Z      切换中文／英文（左键点托盘图示也一样）
    托盘图示右键    选单（切换、结束）

    注音键          打字。大千式键盘，例如 su3cl3 → 你好
    空白            送出（组字中）；候选视窗开启时=下一页十个
    ↓ / ↑           开启／关闭候选视窗
    1 … 9、0        选字模式开启后，选第 1…10 个候选
    ← →             移动候选游标
    Backspace       退一格
    Enter           送出
    Esc             清空


为什么选字前要先开候选视窗？
----------------------------

因为大千式键盘上 1234567890 本身就是注音键：

    1ㄅ  2ㄉ  3ˇ  4ˋ  5ㄓ  6ˊ  7˙  8ㄚ  9ㄞ  0ㄢ

如果数字直接拿去选字，su3cl3 里的 3 就会变成「选第 3 个候选」而不是「ˇ」，
这个输入法就完全不能用了。所以要先用 ↓ 开启候选视窗，数字才用来选字。

平常打字不需要开候选视窗：打 su3cl3 再按空白，直接得到「你好」。

微软新注音、自然输入法也都是这样处理的。


它会学习
--------

当你选了一个和自动选字不同的候选，它会记住。教过一次的词，之后打同样的注音就会
优先出现——例如 ㄔㄨˋ ㄕㄥ 预设是「畜生」，你选一次「畜牲」，之后就会是「畜牲」。

学习纪录存在安装目录的 pingzhu-userdict.txt，是纯文字档，可以直接看、直接编辑、
直接备份。移除程式时会自动备份到 %LOCALAPPDATA%\PingZhu-userdict-backup.txt。


疑难排解
--------

托盘图示看不到？
    按右下角的 ^ 展开隐藏的图示区，把图示拖到工作列上。

打英文变成注音？
    你目前在中文模式。按 Ctrl+Alt+Z 切到英文。

某些视窗打不出中文？
    那个视窗可能以系统管理员权限执行。Windows 不允许一般权限的程式对它注入按键。

程式没反应？
    托盘图示右键 → 结束，然后重新执行。或在工作管理员结束 pingzhu-ime.exe。


解除安装
--------

双击 uninstall.cmd，或开始功能表 → 平注 PingZhu（解除安装）。

会移除程式与捷径，学习纪录会先备份。这个程式不装驱动、不写登录档的输入法项目，
所以移除后不留痕迹。


档案
----

    pingzhu-ime.exe        输入法本体（托盘程式）
    pingzhu_core.dll       Rust 引擎：注音解码、词库、学习（C ABI）
    bopomofo-lm.tsv        语言模型：169,604 条词、131,048 个读音
    pingzhu-userdict.txt   你的学习纪录（第一次教过字之后才会出现）
    install.cmd            / install.ps1      安装
    uninstall.cmd          / uninstall.ps1    解除安装
