平注 PingZhu — Windows 注音輸入法
==================================

版本：0.4.0
授權：MIT
網址：https://github.com/173787247/pingzhu


這是什麼
--------

一個可以在 Windows 上打注音的輸入法。托盤常駐，不需要安裝驅動、不需要管理員權限、
不寫入登錄檔的輸入法設定。

它不是 TSF 文字服務，所以不會出現在語言列，也無法對「以系統管理員身分執行」的視窗
輸入（那是 Windows 的 UIPI 限制）。記事本、瀏覽器、Office、多數應用程式都可以用。


安裝
----

方法一（推薦）：雙擊 install.cmd

方法二：在 PowerShell 執行
    powershell -ExecutionPolicy Bypass -File install.ps1

安裝位置：%LOCALAPPDATA%\Programs\PingZhu
會建立開始功能表捷徑，並加入登入時自動啟動（不想自動啟動就加 -NoStartup）。

不想安裝也可以用：直接雙擊 pingzhu-ime.exe，整個資料夾帶著走。


操作
----

    Ctrl+Alt+Z      切換中文／英文（左鍵點托盤圖示也一樣）
    托盤圖示右鍵    選單（切換、結束）

    注音鍵          打字。大千式鍵盤，例如 su3cl3 → 你好
    空白            開啟候選視窗；再按一次翻下一頁十個
    ↓ / ↑           開啟／關閉候選視窗
    1 … 9、0        選字模式開啟後，選第 1…10 個候選
    ← →             移動候選游標
    Backspace       退一格
    Enter           送出
    Esc             清空


為什麼選字前要先開候選視窗？
----------------------------

因為大千式鍵盤上 1234567890 本身就是注音鍵：

    1ㄅ  2ㄉ  3ˇ  4ˋ  5ㄓ  6ˊ  7˙  8ㄚ  9ㄞ  0ㄢ

如果數字直接拿去選字，su3cl3 裡的 3 就會變成「選第 3 個候選」而不是「ˇ」，
這個輸入法就完全不能用了。所以要先按空白（或 ↓）開啟候選視窗，數字才用來選字。

微軟新注音、自然輸入法也都是這樣處理的。


它會學習
--------

當你選了一個和自動選字不同的候選，它會記住。教過一次的詞，之後打同樣的注音就會
優先出現——例如 ㄔㄨˋ ㄕㄥ 預設是「畜生」，你選一次「畜牲」，之後就會是「畜牲」。

學習紀錄存在安裝目錄的 pingzhu-userdict.txt，是純文字檔，可以直接看、直接編輯、
直接備份。移除程式時會自動備份到 %LOCALAPPDATA%\PingZhu-userdict-backup.txt。


疑難排解
--------

托盤圖示看不到？
    按右下角的 ^ 展開隱藏的圖示區，把圖示拖到工作列上。

打英文變成注音？
    你目前在中文模式。按 Ctrl+Alt+Z 切到英文。

某些視窗打不出中文？
    那個視窗可能以系統管理員權限執行。Windows 不允許一般權限的程式對它注入按鍵。

程式沒反應？
    托盤圖示右鍵 → 結束，然後重新執行。或在工作管理員結束 pingzhu-ime.exe。


解除安裝
--------

雙擊 uninstall.cmd，或開始功能表 → 平注 PingZhu（解除安裝）。

會移除程式與捷徑，學習紀錄會先備份。這個程式不裝驅動、不寫登錄檔的輸入法項目，
所以移除後不留痕跡。


檔案
----

    pingzhu-ime.exe        輸入法本體（托盤程式）
    pingzhu_core.dll       Rust 引擎：注音解碼、詞庫、學習（C ABI）
    bopomofo-lm.tsv        語言模型：169,604 條詞、131,048 個讀音
    pingzhu-userdict.txt   你的學習紀錄（第一次教過字之後才會出現）
    install.cmd            / install.ps1      安裝
    uninstall.cmd          / uninstall.ps1    解除安裝
