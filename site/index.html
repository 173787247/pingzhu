平注 PingZhu引擎 v0.10.12

一份注音解碼引擎，五種平台外殼。開源，MIT。

打注音、出漢字。這個專案把「解碼」單獨做成一份引擎 —— 讀音網格、維特比解句、 候選排序、繁簡轉換 —— 然後讓 Windows、Linux、Android、HarmonyOS、macOS 各自用 一層薄外殼去接。

TypeScript 是規格本身。Rust 核心被 1,532 條記錄下來的按鍵串釘在它身上， 逐條比對組字文字、選定句子、分數與路徑。兩邊一旦分開，測試就會說話。

在瀏覽器裡試打 →

78.82%5,000 句 top-1 準確率（自我一致性上界）
2.889KSPC —— 打出一個字平均按幾個鍵

下載

平台取得方式
Windows 10/11 試打版 · 安裝檔與可攜版 zip
Linux（fcitx5） .deb / .rpm —— 裝完在 fcitx5 設定裡加「平注」
Android 8+ APK —— 側載安裝，再到系統輸入法設定裡啟用
HarmonyOS NEXT 專案 zip —— 用 DevEco 開啟、簽名、執行
macOS 12+ 尚未提供 —— 輸入法要向系統登記，簽章必須是 Apple 簽發的 Developer ID，入會仍在等

引擎

也可以只用引擎，自己寫外殼：

npm install https://github.com/173787247/pingzhu/releases/download/v0.10.12/pingzhu-engine-0.10.12.tgz

GitHub Packages 也有一份（npm install @173787247/pingzhu-engine）， 但即使裝公開套件也要先設一次 token —— 說明在 README 裡。
